# 🏔️ LiveWallpaper — живые 4K-обои для Mac и Windows

Видео крутится бесшовно по кругу **прямо на рабочем столе, под иконками**. Управление — через иконку в меню-баре (Mac) или в трее (Windows): выбор обоев, пауза, следующее видео, папка со своими видео. Запускается само при входе в систему и ставит паузу, когда экран заблокирован.

В комплекте 4 обоев в 4K:

| | |
|---|---|
| **Ущелье** | путник идёт сквозь бесконечное каменное ущелье в тумане, 60 fps |
| **Орёл над Тянь-Шанем** | полёт за беркутом над горами Казахстана |
| **Неоновый закат** | ретровейв: солнце, горы и бегущая неоновая сетка |
| **Градиенты** | плавные шёлковые переливы цвета |

## ⬇️ Скачать

Готовые архивы с видео — в разделе **[Releases](../../releases/latest)**:

- `LiveWallpaper-Mac.zip` — для macOS 13 Ventura и новее
- `LiveWallpaper-Windows.zip` — для Windows 10 / 11

## 🍎 Установка на Mac

1. Распакуй `LiveWallpaper-Mac.zip`.
2. Нажми **правой кнопкой** на `Install.command` → **Открыть** → **Открыть**.
   Двойной клик macOS заблокирует, потому что скрипт не из App Store.
3. Если попросит поставить «инструменты разработчика», согласись, дождись конца и повтори шаг 2.
4. Через минуту в меню-баре сверху справа появится иконка ▶︎, выбери в ней обои.

Удаление: правой кнопкой на `Uninstall.command` → **Открыть**.

Приложение собирается из исходника прямо у тебя на Маке (`mac/Sources/LiveWallpaper/LiveWallpaper.swift`): нативный Swift, AppKit + AVFoundation, без зависимостей.

## 🪟 Установка на Windows

1. Распакуй `LiveWallpaper-Windows.zip` (обязательно распакуй, не запускай из архива).
2. Запусти `LiveWallpaper.exe`.
   Если Windows покажет «Windows защитила ваш компьютер», нажми **Подробнее** → **Выполнить в любом случае**. Так бывает со всеми программами без платной цифровой подписи.
3. Приложение само установится в `%LOCALAPPDATA%\LiveWallpaper` и поставит автозапуск. Иконка появится в трее справа внизу (может прятаться под стрелкой `^`).

Удаление: иконка в трее → **Удалить с компьютера…**

Хочешь собрать exe сам? Запусти `windows/build.bat`: компилятор C# уже есть в каждой Windows 10/11, ставить ничего не нужно.

## 🎬 Свои видео

Иконка → **Открыть папку с видео…** → кидай туда `.mp4` или `.mov`. Видео сразу появится в меню.

- Лучше всего **4K (3840×2160)**.
- На Mac: кодек **HEVC (H.265)**, так он почти не греется.
- На Windows: **H.264 MP4**. HEVC на многих Windows без платного кодека не играет.

Конвертация через ffmpeg:
```bash
# Mac (HEVC, аппаратно)
ffmpeg -i input.mp4 -c:v hevc_videotoolbox -b:v 25M -tag:v hvc1 -an output.mov
# Windows (H.264)
ffmpeg -i input.mp4 -c:v libx264 -crf 20 -pix_fmt yuv420p -an output.mp4
```

## 🧪 Как сделаны обои

«Ущелье», «Неоновый закат» и «Градиенты» не сняты и не сгенерированы нейросетью: **каждый кадр посчитан кодом** (`generator/`). Это Python + NumPy + OpenCV: процедурный шум, 3D-перспектива, туман, лучи света. Петли бесшовные математически: всё движение зависит от фазы `2π·кадр/N`, поэтому последний кадр переходит точно в первый.

```bash
pip install numpy opencv-python
python generator/render_all.py canyon      # → out/Ущелье.mov (нужен ffmpeg)
```

«Орёл» — клип из Kling AI, замедленный в 2 раза интерполяцией кадров, увеличенный до 4K и склеенный в петлю.

## Как это работает

- **Mac:** окно без рамки на уровне `kCGDesktopWindowLevel` на каждом мониторе и во всех Spaces, `AVPlayerLooper` для бесшовного повтора, автозапуск через `launchd`.
- **Windows:** окно встраивается в слой рабочего стола под иконками (`Progman` / `WorkerW`, включая новую схему Windows 11 24H2), видео через Windows Media Player, автозапуск через реестр `HKCU\…\Run`.
